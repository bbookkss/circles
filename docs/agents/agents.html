Circles agents

The two Claude agents in Circles: who calls them, which model answers, every tool they can use, and exactly what each tool can read or change.

Every tool runs as the person asking.

Each tool queries Supabase with the visitor's own client, so row-level security and column grants decide what the agent can see, not its prompt. The agent can never reach more than that person could open in the app. And the agent proposes; the person decides. No tool changes anything on its own.

When the window isn't open yet, the validate_check_in trigger refuses the answer. A new table holds it, and a cron applies it once the window opens.

  • No writes from the model. Every change goes through a button the person taps, and runs as that person.
